# Book Finder

A web app that searches millions of books using the Open Library API.

## Features

- Search books by title or author
- Filter results by publish year
- Book covers, authors and publish year
- Responsive design (mobile and desktop)
- Error handling for failed requests

## Technologies

- HTML, CSS
- JavaScript (ES6): Fetch API, Async/Await, Promises
- Open Library Search API: https://openlibrary.org/dev/docs/api/search

## How to run

1. Clone the repository:
   ```
   git clone https://github.com/Moayad0076/book-finder.git
   ```
2. Open the folder in VS Code.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Type a book name or author (in English) and press Search.
